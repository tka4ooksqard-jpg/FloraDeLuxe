## Підсумок для власника

1. **Точно згенеровані / не ваші фото для production:** Hero premium, категорії `*-premium`, галерея `*-premium`, сцени, прапори країн, OG.  
2. **Підтвердити або замінити:** відео в `public/videos/warehouse/`, фото `/about`.  
3. **Можна лишати:** логотип (після «так»), декоративну grain-текстуру.  
4. **Найкраще джерело заміни:** `archive/real-media/` + нова зйомка залу/партій.  
5. До підтвердження сайт **не називає** ці кадри «реальними фото конкретного складу».
